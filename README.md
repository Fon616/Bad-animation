# Bad-animation  

## Основное  

Плагин для анимирования своих сообщений  
По большей части написан через agnes 3.0  flash  
Лицензию ставить не буду, делайте с этим слопом что пожелаете

## Режимы  

5 режимов анимации:  
Побуквенный вывод  
Заго с его очисткой  
Рандомно заменяющиеся на нужный текст  
Расшифровка  
Волна  

## Использование  

"/p 10 ;"
/ - начало команды  
P - настраиваемая буква тригер  
10 - секунды (опционально, если не прописаны, берётся дефолт из настроек)  
; - завершение
